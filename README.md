# Sales Analysis Using Python

## Project Overview
This project performs exploratory sales analysis using Python. It examines sales, profit, quantity, discount, product categories, sub-categories, regions, and customer segments.

## Objectives
- Understand overall sales and profit performance
- Analyze category and sub-category performance
- Compare regional sales and profit
- Analyze customer segments
- Study the relationship between discount and profit
- Generate visualizations and data-driven findings

## Dataset
The project uses the public Sample Superstore dataset.

Dataset repository:
https://github.com/atharvadhankarr/SampleSuperstore-Dataset

Direct CSV:
https://raw.githubusercontent.com/atharvadhankarr/SampleSuperstore-Dataset/main/SampleSuperstore.csv

The dataset contains 9,994 transaction records and includes fields such as Ship Mode, Segment, City, State, Region, Category, Sub-Category, Sales, Quantity, Discount, and Profit.

## How to Run
1. Install Python 3.
2. Install the packages listed in `requirements.txt`.
3. Open `Meghana_SalesAnalysis.ipynb` in Jupyter Notebook or Google Colab.
4. Run all cells from top to bottom.
5. The notebook loads the dataset from the public CSV source and generates tables, charts, KPIs, and findings.

## Expected Analysis
The notebook covers:
- Data inspection
- Data cleaning
- KPI calculation
- Category analysis
- Regional analysis
- Customer segment analysis
- Sub-category analysis
- Discount vs profit analysis
- Automatically generated findings

## Note
The dataset is a public Sample Superstore dataset used for educational/data-analysis practice. The results shown by the notebook are calculated from the dataset when the notebook is executed.
